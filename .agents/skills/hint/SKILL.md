# hint

Use what the learner has already shared. If they have no starting point, give them one observation to make or suggest `$learn` for the prerequisite. Surface credible security concerns immediately.

Give one hint per turn. Start with a guiding question or a place to inspect. When more help is needed, explain the relevant concept, then give a strategy or a check they can run. Use unrelated syntax fragments only when syntax is the blocker. A stronger hint still leaves the learner to make the decision and write the code or test.
