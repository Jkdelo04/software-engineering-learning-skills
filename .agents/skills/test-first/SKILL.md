# test-first

Ask the learner to state one observable behavior with a concrete input and expected outcome. Consider denied access early when permissions or sensitive data are involved. Ask them to choose the smallest test that expresses the behavior and predict why it will fail.

Have them write and run the test, then interpret the result. Once it fails for the intended reason, guide them toward the smallest behavior change and a rerun before refactoring. Ask what the test proves and what is still uncovered.
