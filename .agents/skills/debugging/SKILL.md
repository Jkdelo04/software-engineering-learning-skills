# debugging

Use existing evidence to establish expected and observed behavior. Raise credible security issues first. Ask for a hypothesis if the learner has yet to provide one.

Pick one observation that distinguishes their hypothesis from a plausible alternative. Ask what they expect before they run it. Narrow or revise the hypothesis from the result. Once resolved, ask what established the cause and how they would catch the regression.
