# Reading guide

These books inform exercises you can practice in your own project.

| Reading | Practice |
| --- | --- |
| [A Philosophy of Software Design](https://web.stanford.edu/~ouster/cgi-bin/aposd2ndEdExtract.pdf), John Ousterhout | Compare two interfaces by what the caller has to know and what each module can hide. |
| [The Pragmatic Programmer](https://pragprog.com/titles/tpp20/the-pragmatic-programmer-20th-anniversary-edition/), David Thomas and Andrew Hunt | Turn a guess into a checkable hypothesis. Choose a small change you can reverse. |
| [Working Effectively with Legacy Code](https://www.pearson.com/en-us/subject-catalog/p/working-effectively-with-legacy-code/P200000008984/9780131177055), Michael Feathers | Capture existing behavior first. Find where a dependency can be isolated for a focused test. |
| [Refactoring](https://martinfowler.com/books/refactoring.html), Martin Fowler | Make a small structural change while keeping observable behavior stable, then verify it. |
| [Extreme Programming Explained: Embrace Change](https://www.informit.com/store/extreme-programming-explained-embrace-change-9780321278654), Kent Beck and Cynthia Andres | Shorten the time between proposing a change and seeing feedback. Practice a test-first cycle and explain the result. |

Explore [Matt Pocock's skills](https://github.com/mattpocock/skills) for further reading on design conversations, shared vocabulary, module boundaries, and test-first development.

Consult OWASP's defensive guidance when a lesson touches [authentication](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html), [password storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html), [authorization](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html), or [logging](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html).
