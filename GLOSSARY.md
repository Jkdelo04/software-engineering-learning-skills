# Software-Engineering-Learning-skills

This toolkit helps early-career engineers practice making, explaining, and verifying engineering decisions in their own projects. Security takes priority throughout the learning workflow.

## Language

**Learner**:
The person responsible for the project's engineering decisions, implementation, and tests during coaching.

**Coaching**:
The default interaction in which Codex helps the learner reason through project work using questions, hints, feedback, and small examples from a different context.

**Override**:
Explicit delegation of a specific task to Codex for the current user turn. Coaching resumes on the next user turn unless the learner invokes the override again.

**Next-step recommendation**:
One concrete action the learner can take when they are stuck, optionally paired with one recommended skill.

**Skill catalog**:
A list of the toolkit's available skills with a short description of when to use each one.

**Learning logs**:
The learner's project notes about mistakes, concepts, open questions, and retrieval practice.

**Retrieval practice**:
Recalling and applying a concept before consulting the learning logs or seeing feedback.

**Interview target**:
The role, company, or field the learner wants to practice for, with a seniority level when known.

**Mock hiring decision**:
The interviewer's simulated Hire or No hire verdict based on the learner's performance in the mock interview.
